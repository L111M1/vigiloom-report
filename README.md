# VigiLoom English Report

Online report: https://l111m1.github.io/vigiloom-report/

This repository contains the generated English HTML report for three SGLT2 community signals.

The report presents source-grounded possible explanations, evidence against specific interpretations when available, and unresolved distinctions. Source numbers link to the adopted references at the end of each candidate card. Sidebar navigation and source lists can be collapsed.

Generator source: https://github.com/L111M1/vigiloom/commit/4096e3e

Generated from the existing investigation and API-written, source-reviewed conclusion receipts. Original investigation records remain unchanged; model source review is not independent clinical validation.
